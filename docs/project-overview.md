# Project Overview

## Name
Blood Donor Finder

## Purpose
To provide a platform that connects people who need blood with registered donors through blood-group and location-based search.

## Main Roles
- Donor
- Requester
- Administrator

## Core Modules
- Registration and authentication
- Donor profile and availability
- Donor search
- Blood requests
- Notifications
- Request status tracking
- Admin dashboard

## Key Requirement
Donor contact details and other personal information must not be exposed publicly.
